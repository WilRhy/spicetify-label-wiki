# Aboutify Contribution Help
If you wanna help contribute a Label Wiki page, then follow this (sort of) easy tutorial.

## 1. Fork this repository.
Number 1, you have to fork this repository so you can make your own copy and edit the label you want to be in the database in.

## 2. Edit database.json
There is 2 or more labels as examples to a new label. Copy the code from the other labels in the database and replace information with yours without removing the other labels. You may remove the "Paper Vinyl Records" data from the file as that label is hardcoded into the extension.

## 3. Submit a pull request
After you are done putting in your label information, commit your changes, and go to the "Pull requests" tab. Then, click "New pull request" and continue creating a pull request.

## 4. Wait.
When the pull request is created, it might take about under an hour to 2+ hours for me to approve it and merge it to the actual database.

## 5. Approval
Once I have merged your pull request, you are able to see your label in the Labels Hub.
